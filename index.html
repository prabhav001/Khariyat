Fictional sample data. Not a real society or real people. Prototype only: data stays in this browser’s local storage (not encrypted), there are no user accounts, and Khairiyat never calls or messages anyone.

Khairiyat (ख़ैरियत) is a clickable prototype. Everything here is fictional. Its aim is coordination: no unresolved household or welfare case without an accepted next step. That is not a safety guarantee, and Khairiyat never decides that anyone is safe, missing or in danger.

Data is kept only in this browser’s local storage and is not encrypted; anyone using this browser profile can see it. There are no accounts or role-based permissions; messages for wardens, helpers and residents carry limited information by design, not by access control. Nothing leaves this page except text you copy and CSV files you choose to download.
